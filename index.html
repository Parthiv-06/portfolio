Claim Handling System

Not a claim

An inbox‑to‑resolution pipeline: incoming customer emails are classified, routed, and resolved by a chain of specialist agents—turning an 8‑minute human triage into a 30‑second autonomous one.

Problem

The customer order desk receives hundreds of mails daily. Humans must decide: is it a claim? If yes, what type? What action is needed? This is slow, inconsistent, and doesn't scale.

Approach

  • Mail ingested via IMAP and parsed into structured payload.
  • LangGraph state machine routes it through Classifier → Extractor → Validator agents.
  • Each agent uses prompt engineering + tool calls (order DB, policy DB).
  • Final agent drafts a reply; supervisor agent reviews before sending.

Outcome

92%auto‑resolved
30savg. triage
15×throughput

! anomaly

A self‑healing monitoring layer. PLC sensor streams are analyzed in real time by reasoning agents that detect anomalies, diagnose root cause, and trigger corrective actions—without human relay.

Problem

Factory floor sensors generate noisy, high‑frequency streams. Traditional threshold alarms miss pattern‑based failures and create alert fatigue.

Approach

  • Kafka ingests PLC telemetry; windowed features computed on the fly.
  • A LangChain agent examines anomalies with access to runbooks and past incident memory.
  • The agent proposes, validates, and executes corrective playbooks via tool calls.
  • Outcome + rationale logged back to the vector memory for continuous learning.

Outcome

4.1×faster MTTR
67%false alarms cut

A Medallion data pipeline on Azure. Raw tenant sales data is ingested, progressively refined through Bronze → Silver → Gold layers, and delivered business‑analytics‑ready.

Problem

Tenants dumped messy, inconsistent sales exports. Analysts spent 70% of their time cleaning instead of analyzing.

Approach

  • Azure Data Factory orchestrates ingestion from blob storage.
  • Bronze retains raw, Silver applies schema + quality rules, Gold publishes star‑schema marts.
  • Synapse serverless pools expose Gold to Power BI and downstream apps.
  • Incremental merges + data contracts keep pipelines resilient to upstream drift.

Outcome

−70%cleaning time
Dailyrefresh SLA
12TBmanaged
Azure Data Factory Synapse Medallion SQL Power BI
